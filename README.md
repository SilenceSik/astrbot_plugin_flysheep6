# flysheep6 游戏日报

AstrBot 插件：每天查询 [flysheep 资源避难所](https://www.flysheep6.com/) 最近三天发布的游戏，输出游戏目录、简介和原文链接。

默认查询站点首页的四个游戏目录：

- PC 单机大作（分类 ID 4）
- VR 游戏（分类 ID 5）
- 小游戏/独立游戏（分类 ID 32）
- 模拟器整合游戏（分类 ID 72）

## 命令

- `/避难所游戏`：立即查询最近三天，手动查询始终返回完整结果。
- `/避难所搜索 游戏名`：不限发布时间，按关键词定向搜索游戏目录、简介和原文链接。
- `/避难所订阅`：管理员订阅当前群聊或私聊的每日推送。
- `/避难所退订`：管理员取消当前会话订阅。
- `/避难所状态`：管理员查看订阅数量、推送时间和最近运行状态。

## 定时推送

默认每天 `09:00`（`Asia/Shanghai`）执行，每次都完整发送最近三天的结果，不按历史推送记录去重。最近三天没有游戏时默认静默。

可在 AstrBot 插件配置页调整时间、时区、查询天数、分类、简介长度、单次条数、搜索结果数和空结果提醒。兼容旧版本的 `only_new_on_schedule` 开关仍然保留，开启后才会恢复去重。修改定时配置后请重载插件。

## 安装

在 AstrBot 插件管理页通过仓库地址 `https://github.com/SilenceSik/astrbot_plugin_flysheep6` 安装，或将整个 `astrbot_plugin_flysheep6` 目录放入 AstrBot 的 `data/plugins/` 后重载插件。插件使用 Python 标准库访问站点，没有额外 Python 依赖。

订阅会话最简单的方式，是在目标群聊或私聊里由管理员发送 `/避难所订阅`。也可以在配置页直接填写 AstrBot 的 `unified_msg_origin` 到 `targets` 列表。
